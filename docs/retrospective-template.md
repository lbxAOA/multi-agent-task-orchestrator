# 多智能体任务复盘模板

> 本模板用于按需创建独立复盘记录，不要求每个任务都使用。只有用户或任务契约明确启用复盘，或允许记录具有明显复用价值的故障与经验时，才创建记录。
>
> 默认路径：`docs/retrospectives/YYYY-MM-DD-<简短-kebab-case-任务名>.md`。同名时追加 `-2`、`-3`，不得覆盖历史记录。
>
> 只记录真实可核验证据。绝不记录密码、密钥、token、`.env` 内容或完整敏感输出。未执行的项目必须明确写为“未运行”并解释原因。
